Diretrizes de Uso e Política de PrivacidadeUsage Guidelines & Privacy Policy

Leia estes termos antes de usar o bot, o site ou a API.Read these terms before using the bot, website or API.

1Propriedade da conta e dos dadosOwnership of Account and Data

Os usuários mantêm a propriedade total de suas Coins, de sua conta e de todos os dados associados ao seu uso. A plataforma não reivindica propriedade sobre ativos, identificadores ou detalhes de conta dos usuários.

Users retain full ownership of their Coins, their account, and all data associated with their usage. The platform does not claim ownership over user assets, identifiers, or account details.

2Remoção de dados controlada pelo usuárioUser-Controlled Data Removal

Os usuários são responsáveis por excluir suas contas e dados caso desejem interromper o uso (no site: Conta → Zona de perigo → Excluir conta). A plataforma não exclui contas em nome dos usuários, exceto quando necessário para a integridade do sistema ou em caso de violação de políticas.

Users are responsible for deleting their accounts and data if they wish to discontinue usage (on the website: Account → Danger zone → Delete account). The platform will not delete accounts on behalf of users except when required for system integrity or policy breaches.

3Não armazenamento de dados sensíveisNo Storage of Sensitive Data

A plataforma não armazena dados pessoais sensíveis como senhas em texto puro, nomes, endereços, telefones, documentos de identificação ou registros de IP além do tecnicamente necessário. Apenas as informações técnicas mínimas exigidas para operar o serviço são processadas.

The platform does not store sensitive personal data such as plaintext passwords, names, addresses, phone numbers, identification documents, or IP logs beyond technical necessities. Only the minimum technical information required to operate the service is processed.

4Visibilidade de dados públicosPublic Data Visibility

Nomes de usuário, IDs de conta, IDs de cartão, informações de transações e demais dados públicos são de responsabilidade do usuário. Escolher identificadores públicos implica possível visibilidade pelo site, pela API ou por integrações — a plataforma não se responsabiliza por exposições causadas por identificadores escolhidos pelo usuário.

Comprovantes possuem um QR code que leva à página pública da transação (/tx.html?id=…), que exibe ID, data, contas de origem e destino e valor, com base no endpoint público GET /api/tx/:txid. Qualquer pessoa com o ID da transação pode consultá-la.

Usernames, account IDs, card IDs, transaction information and other public data are the user's responsibility. Choosing public identifiers implies potential visibility through the website, API or integrations — the platform is not liable for exposure caused by user-selected identifiers.

Receipts carry a QR code linking to the public transaction page (/tx.html?id=…), which shows ID, date, source and destination accounts and amount, based on the public endpoint GET /api/tx/:txid. Anyone with the transaction ID can look it up.

5Criptografia e segurançaEncryption & Security

Informações sensíveis da conta são armazenadas com hash criptográfico seguro de mão única. Senhas e elementos de autenticação não podem ser revertidos nem lidos em texto puro. O desenho do sistema impede que a equipe ou terceiros extraiam segredos sensíveis.

Sensitive account information is stored using secure, one-way cryptographic hashing. Passwords and authentication elements cannot be reversed or read in plaintext. System design prevents staff or third parties from extracting sensitive secrets.

6Sem acesso humano aos bancos de dadosNo Human Access to Databases

As ações de conta são executadas por sistemas automatizados. Nenhum humano acessa ou modifica rotineiramente o conteúdo do banco de dados de produção, minimizando a exposição manual dos dados dos usuários.

Account actions are executed through automated systems. No human routinely accesses or modifies the production database contents, minimizing manual exposure of user data.

Ao utilizar serviços de terceiros, o usuário ou o operador desse serviço é responsável pela forma como os dados são tratados. A plataforma não se responsabiliza pelo armazenamento, exibição ou processamento, por terceiros, de dados obtidos via API.

When using third-party services, the user or operator of that service is responsible for how data is handled. The platform is not liable for third-party storage, display, or processing of data obtained via the API.

8Minimização de dadosData Minimization

O sistema armazena apenas os dados técnicos mínimos necessários para funcionar, como:

  • identificadores internos
  • credenciais com hash
  • registros de transações
  • informações de saldo

The system stores only minimal technical data necessary for functionality, such as:

  • internal identifiers
  • hashed credentials
  • transaction entries
  • balance information

9Ausência de informações de identidade realAbsence of Real Identity Information

A plataforma não coleta nomes, e-mails, endereços postais, telefones ou documentos de identidade. Os usuários permanecem anônimos, a menos que divulguem voluntariamente informações de identidade em outro lugar.

The platform does not collect names, emails, postal addresses, phone numbers or identity documents. Users remain anonymous unless they voluntarily disclose identity information elsewhere.

10Transparência de armazenamento e usoTransparency of Storage & Usage

Elementos públicos da plataforma — saldos, transações, nomes de usuário — podem ficar visíveis dependendo de como os usuários interagem com o sistema (por exemplo, no ranking e nas estatísticas públicas da aba Rede). Os usuários aceitam a responsabilidade de manter a privacidade dos identificadores escolhidos.

Public platform elements — balances, transactions, usernames — may be visible depending on how users interact with the system (for example, in the ranking and public statistics on the Network tab). Users accept responsibility for maintaining privacy of chosen identifiers.

Os usuários são responsáveis por:

  • proteger suas credenciais
  • proteger os códigos do cartão
  • escolher nomes de usuário que não os identifiquem, se desejarem
  • excluir contas ou dados quando necessário
  • garantir que suas escolhas de privacidade estejam de acordo com seus padrões de uso

A plataforma não se responsabiliza por exposições causadas por escolhas do usuário.

Users are responsible for:

  • securing their credentials
  • protecting card codes
  • choosing non-identifying usernames if desired
  • deleting accounts or data when needed
  • ensuring privacy choices align with usage patterns

The platform is not liable for exposures caused by user choices.

12Medidas de segurançaSecurity Measures

São usadas práticas de segurança padrão, incluindo senhas com hash, acesso restrito ao banco de dados e operações automatizadas. No entanto, nenhum sistema pode ser garantido como 100% seguro: os usuários reconhecem e aceitam essa limitação.

Standard security practices are used, including hashed passwords, restricted database access and automated operations. However, no system can be guaranteed 100% secure: users acknowledge and accept this limitation.

13Sem responsabilidade legal por ações do usuárioNo Legal Responsibility for User Actions

A plataforma não é responsável pelo comportamento dos usuários, pelo tratamento de dados da API por terceiros nem por questões legais decorrentes de ações dos usuários. A responsabilidade legal pelas ações do usuário é do próprio usuário.

The platform is not responsible for user behavior, third-party handling of API data, or legal issues arising from user actions. Legal liability for user actions rests with the user.

14Persistência de Coins e tokens econômicosPersistence of Coins & Economic Tokens

As Coins são armazenadas na economia interna da plataforma e são imutáveis fora das regras da plataforma. Excluir uma conta remove o acesso, mas não apaga o registro econômico histórico — os saldos permanecem como parte dos dados agregados do sistema.

As Coins não têm valor fixo no mundo real; são apenas tokens internos. A plataforma não oferece reembolso, compensação ou restauração de Coins em nenhuma circunstância.

Todas as decisões envolvendo Coins — transferências, compartilhamento de códigos de cartão, backups, exclusões — são de responsabilidade do usuário. A plataforma não pode reverter nem compensar essas ações.

Coins are stored within the platform's internal economy and are immutable outside of platform rules. Deleting an account removes access but does not erase the historical economic record — balances remain part of aggregated system data.

Coins have no fixed real-world value; they are internal tokens only. The platform provides no refunds, compensation, or restoration of Coins under any circumstance.

All decisions involving Coins — transfers, sharing card codes, backups, deletions — are the user's responsibility. The platform cannot reverse or compensate for these actions.
